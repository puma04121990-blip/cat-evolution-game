# Архитектура профиля VK и облачного сохранения

## Сценарий запуска

После `VKWebAppInit` игра запрашивает `VKWebAppGetUserInfo` без дополнительных прав. Успешный ответ означает, что игрок уже вошёл в VK-контексте: интерфейс показывает его имя и статус синхронизации. В браузере вне VK Bridge остаётся нейтральный статус «Локальный профиль»; игра не блокирует прогресс и не имитирует авторизацию.

## Приоритет сохранений

1. Игра мгновенно загружает локальный снимок, чтобы не задерживать старт.
2. После инициализации VK Bridge запрашивается ключ `tiny_skyline_save_v2` через `VKWebAppStorageGet`.
3. Если облачный снимок валиден и его `lastSave` новее локального, он становится текущим состоянием; в противном случае локальное состояние отправляется в облако.
4. Любое значимое игровое действие обновляет `localStorage` и ставит облачную запись в очередь с дебаунсом. Это исключает отправку запроса на каждый клик.
5. При ошибке Bridge локальное сохранение остаётся рабочим, а статус уведомляет только в отладочном журнале, без пугающего игрока сообщения.

## Данные

В облако пишется компактный JSON-снимок игровой экономики, контрактов, коллекции и настроек звука. Временное событие не считается долговременной ценностью и при сериализации отбрасывается. Объём снапшота проверяется до записи, чтобы не превысить установленный VK Storage лимит для сериализованной строки.

## Звуковая обратная связь

| Событие | Отклик |
|---|---|
| Обычный заряд | Короткий восходящий тон с динамикой, ограниченный по частоте. |
| Энерговсплеск | Двухнотный акцент с лёгкой вибрацией. |
| Покупка | Короткий строительный арпеджио. |
| Контракт и артефакт | Яркий трёхнотный мотив. |
| Новый район | Более длинная праздничная последовательность и частицы. |
| Небесное событие | Мягкий сигнал начала без агрессивной громкости. |

Эффекты синтезируются Web Audio после первого действия игрока и имеют независимый от музыки выключатель. Это сохраняет малый размер игры и работает при локальной проверке без дополнительных аудиофайлов.
