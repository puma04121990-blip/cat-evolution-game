# GamePush — технические заметки для билда

## Подключение

Официальная инструкция требует вставить в `index.html` загрузчик SDK, сформированный в кабинете GamePush с реальными `projectId` и `publicToken`. После запуска вызывается `window.onGPInit(gp)`; перед работой с данными игрока нужно дождаться `await gp.player.ready`.[1]

## Сохранения

Для облачного сохранения в панели GamePush необходимо создать строковое поле игрока `save`. Прогресс читается через `gp.player.get('save')`, записывается через `gp.player.set('save', value)` и подтверждается `await gp.player.sync()`. Данные автоматически доступны после инициализации игрока.[2]

## Реклама

Менеджер `gp.ads` предоставляет флаги доступности и методы `showRewardedVideo`, `showFullscreen`, `showPreloader` и `showSticky`. Rewarded-видео должно вызываться только по запросу игрока и давать награду после успешного результата. Полноэкранная реклама предназначена для естественных пауз, а sticky-баннер не должен перекрывать игровую область.[3]

## Необходимое действие перед публикацией

Без созданного проекта и ключей из кабинета SDK намеренно не загружается. Игра сохраняет полноценный автономный запуск на `localStorage`; после добавления кода загрузчика из кабинета включатся облачное сохранение, preloader, sticky и рекламные вызовы.

## Проверка автономного запуска

После удаления прежней платформенной интеграции игра открылась без внешнего SDK: отображаются локальное сохранение, городской грант, ускоритель дохода и маршруты экспедиций. Консоль браузера не зафиксировала ошибок при запуске.

Проверка локального fallback подтвердила выдачу городского гранта, активацию двухминутного буста дохода, мгновенное завершение экспедиции и удвоенную оффлайн-награду. Контролируемый mock GamePush подтвердил вызов `onGPInit`, готовность игрока, rewarded-награду, fullscreen-сценарий, возврат игры из паузы и сохранение состояния без внешней сети.

Контрольные снимки подтвердили, что кнопка буста не пересекается с показателями энергии на 375 × 812, а на 1280 × 480 остаются видимыми вкладки, контракт, несколько карточек развития и нижние действия. Новые элементы не нарушили компактную альбомную компоновку.

Повторный запуск подтвердил корректную работу автономного режима после добавления сохранения при уходе со страницы: снимок записывается локально, прежний платформенный объект отсутствует, а `window.onGPInit` доступна для будущего подключения GamePush SDK.
