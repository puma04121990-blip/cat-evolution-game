# Город в облаках

**«Город в облаках»** — русскоязычная HTML5 idle-игра о развитии небесной столицы. Игрок заряжает городское ядро, строит инфраструктуру, открывает десять районов, получает пассивный доход и начинает новые высоты с постоянным коэффициентом развития.

## Что реализовано

| Направление | Возможности |
|---|---|
| Игровой цикл | Заряд ядра, критический энерговсплеск, восемь улучшений, пассивный доход, офлайн-награда, небесные экспедиции, звёздные исследования и новая высота. |
| Городская сцена | Квадратная статичная иллюстрация небесного острова без дорожной застройки, NPC и архитектурных анимаций. Восемь сцен автоматически сменяются по десяти этапам: от маяка к сети связанных островов. Главный клик сохраняет начисление энергии и краткий отклик. |
| Удержание | Районные контракты, временные небесные события, три маршрута экспедиций, городские марки, звёздные исследования и коллекция из шести архитектурных артефактов с постоянными бонусами. |
| Удобство | Типографика Manrope с контрастной иерархией, тематические SVG-иконки вместо буквенных кодов, полностью видимые статусы «доступно», понятная недостача ресурсов, обучающая подсказка и верхние уведомления без перекрытия кнопок. |
| Адаптивность | Портретный мобильный режим, компактный альбомный режим и двухколоночная веб-раскладка. |
| Аудио | Оригинальная инструментальная фоновая музыка, отдельные мотивы клика, энерговсплеска, покупки, контракта, артефакта и открытия района; независимые переключатели музыки и эффектов. |
| VK | Профиль текущего игрока через `VKWebAppGetUserInfo`, облачное сохранение через VK Storage, безопасный fallback для обычного браузера и обёртки для тактильной отдачи. |

## Локальный запуск

Откройте `index.html` через статический сервер или напрямую в современном браузере. В обычном браузере игра работает с `localStorage`; VK Bridge и платформенные сценарии не мешают локальному запуску.

## Подготовка к VK Играм

1. Создайте игру в кабинете разработчика VK и добавьте тестовую группу.
2. Проверьте запуск внутри клиентов Android, iOS, Mobile Web и Web. Внутри VK обязателен единственный вызов `VKWebAppInit`; он уже добавлен в игру. [Документация](https://dev.vk.com/bridge/VKWebAppInit)
3. Проверьте реальные события VK Bridge: инициализацию, получение профиля, чтение и запись VK Storage, виброотклик, рекламный формат и сценарий сворачивания/возврата. Локальный браузер не воспроизводит эти клиентские возможности.
4. Загрузите ZIP-архив, в котором `index.html` лежит в корне, а папка `assets/` находится рядом с ним.
5. Добавьте `assets/vk-cover-800x470.jpg`, `assets/vk-icon-512.png`, русское описание, возрастную маркировку и скриншоты портретного и альбомного режимов.
6. Пройдите тестирование в группе, затем отправьте игру на модерацию.

## Важно

Вознаграждаемая реклама и облачное сохранение требуют включения и проверки в созданном приложении VK. До подключения платформенных прав городской грант использует безопасный локальный fallback, а сохранение остаётся на устройстве пользователя.
