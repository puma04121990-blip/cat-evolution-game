# Эволюция Кота (Cat Evolution Clicker)

Простая, но полноценная idle-кликер игра для Яндекс.Игр.

## Как играть
- Кликай по коту, чтобы получать рыбок 🐟
- Покупай улучшения в магазине
- Кот эволюционирует по мере накопления общего прогресса
- Делай престиж для постоянного множителя

## Особенности
- 10 стадий эволюции кота
- 8 видов улучшений
- Система престижа
- Критические клики (8% шанс x5)
- Сохранение прогресса (localStorage)
- Оффлайн-доход (50% эффективности, до 8 часов)
- Звуковые эффекты
- Адаптив под мобильные и десктоп
- Готовность к Яндекс Games SDK (GameReady вызывается)

## Технические требования Яндекс.Игр
- ✅ index.html в корне
- ✅ Нет пробелов и русских букв в именах файлов
- ✅ Размер сильно меньше 100 МБ
- ✅ SDK инициализируется
- ✅ GameReady вызывается
- ✅ Работает на мобильных и десктопе
- ✅ Нет внешних зависимостей (кроме SDK)
- ✅ Прогресс сохраняется

## Запуск локально
Просто открой `index.html` в браузере.

## Для публикации на Яндекс.Играх
1. Заархивируй папку (чтобы index.html был в корне архива)
2. Создай черновик в консоли разработчика
3. Загрузи архив
4. Заполни описание, иконку, обложку, скриншоты
5. Отправь на модерацию
