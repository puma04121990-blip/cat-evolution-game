# Город в облаках

**«Город в облаках»** — русскоязычная HTML5 idle-игра о развитии небесной столицы. Игрок заряжает городское ядро, строит инфраструктуру, открывает десять районов, получает пассивный доход и начинает новые высоты с постоянным коэффициентом развития.

## Что реализовано

| Направление | Возможности |
|---|---|
| Игровой цикл | Заряд ядра, критический энерговсплеск, восемь улучшений, пассивный доход, офлайн-награда, небесные экспедиции, звёздные исследования и новая высота. |
| Городская сцена | Квадратная статичная иллюстрация небесного острова без дорожной застройки, NPC и архитектурных анимаций. Восемь сцен автоматически сменяются по десяти этапам: от маяка к сети связанных островов. Главный клик сохраняет начисление энергии и краткий отклик. |
| Удержание | Районные контракты, временные небесные события, три маршрута экспедиций со случайными встречами, достижения за их полное освоение, городские марки, звёздные исследования и коллекция из шести архитектурных артефактов с постоянными бонусами. |
| Удобство | Типографика Manrope с контрастной иерархией, тематические SVG-иконки вместо буквенных кодов, полностью видимые статусы «доступно», понятная недостача ресурсов, обучающая подсказка и верхние уведомления без перекрытия кнопок. |
| Адаптивность | Портретный мобильный режим, компактный альбомный режим и двухколоночная веб-раскладка. |
| Аудио | Оригинальная инструментальная фоновая музыка, отдельные мотивы клика, энерговсплеска, покупки, контракта, артефакта, исследования и открытия района; независимые переключатели музыки и эффектов. |
| GamePush | Локальное сохранение без SDK, подготовленный cloud-save адаптер и безопасные рекламные точки после подключения проекта GamePush. |

## Локальный запуск

Откройте `index.html` через статический сервер или напрямую в современном браузере. Без внешнего SDK игра полностью работает с `localStorage` и не требует платформенной авторизации.

## Подготовка к GamePush

1. Создайте проект в кабинете GamePush и заведите строковое поле игрока `save`.
2. Вставьте точный загрузчик SDK, полученный в кабинете, перед закрывающим `body`; после этого адаптер автоматически обработает `onGPInit`.
3. Проверьте облачное сохранение, preloader, sticky и rewarded-сценарии в тестовом запуске. До подключения SDK игра остаётся автономной и сохраняет прогресс локально.

## Важно

Вознаграждаемая реклама и облачное сохранение включатся после добавления проекта и SDK GamePush. До этого городской грант и усиления используют безопасный локальный fallback, а сохранение остаётся на устройстве пользователя.
