# Город в облаках

**«Город в облаках»** — русскоязычная idle-кликер игра для Яндекс Игр. Игрок заряжает городское ядро, накапливает энергию города, развивает воздушную инфраструктуру и постепенно превращает небольшую платформу в небесную столицу.

## Как играть

Нажимайте на городское ядро, чтобы получать энергию. В разделе «Развитие города» покупайте инфраструктурные улучшения для увеличения силы заряда и пассивного дохода. По мере накопления общей энергии город переходит через десять визуальных стадий. После достижения миллиона единиц энергии можно открыть «Новую высоту»: текущий город начнёт развитие заново, а постоянный коэффициент развития сохранится.

## Особенности

| Возможность | Описание |
|---|---|
| Десять стадий | Путь от Небесной платформы до Города мечты. |
| Восемь улучшений | Городская инфраструктура с теми же числовыми эффектами, что и в исходной версии. |
| Новая высота | Престиж с постоянным коэффициентом развития. |
| Энерговсплеск | Критический заряд с шансом 8% и пятикратной наградой. |
| Автосохранение | Локальный прогресс и облачное сохранение через SDK Яндекс Игр. |
| Накопленная энергия | До восьми часов офлайн-дохода с эффективностью 50%. |
| Русская локализация | Все игровые названия, кнопки, сообщения и числовые сокращения адаптированы для русскоязычной аудитории. |

## Локальный запуск

Откройте `index.html` в браузере. В локальном режиме реклама заменяется мгновенной выдачей награды, а сохранение работает через `localStorage`.

## Подготовка к публикации в Яндекс Играх

1. Убедитесь, что `index.html` расположен в корне архива.
2. Упакуйте содержимое папки в ZIP-архив.
3. Создайте черновик игры в консоли разработчика и загрузите архив.
4. Добавьте обложку, иконку, описание и скриншоты.
5. Отправьте игру на модерацию.

## Технические условия

Проект не использует сторонних библиотек. SDK Яндекс Игр инициализируется, `LoadingAPI.ready()` вызывается после инициализации, а игра сохраняет прогресс в локальном и облачном режиме.
